# SDK Video Generation Examples

This directory contains examples for testing the Verlon AI SDK's video generation functionality.

## Setup

1. Copy `.env.example` to `.env`
2. Fill in your Verlon API key and video gate ID
3. Install dependencies: `pnpm install`

## Examples

- `basic.ts` - Basic video generation with just a prompt
- `sizes.ts` - Video generation with custom size parameter

## Running

```bash
pnpm run basic
pnpm run sizes
```

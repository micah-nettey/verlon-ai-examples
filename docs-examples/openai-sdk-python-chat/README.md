# OpenAI SDK Python Chat Examples

This directory contains examples for using the OpenAI Python SDK with Verlon AI for chat completions.

## Setup

1. Copy `.env.example` to `.env`
2. Fill in your Verlon API key and gate ID
3. Install dependencies: `pip install -r requirements.txt`

## Examples

- `basic.py` - Basic chat completion with the OpenAI SDK
- `streaming.py` - Streaming chat completion example

## Running

```bash
python basic.py
python streaming.py
```

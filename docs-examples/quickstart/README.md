# Quickstart Example

This example tests the code from the [Quickstart documentation](https://docs.useverlon.ai/getting-started/quickstart).

## Setup

1. Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

2. Fill in your credentials in `.env`:
```
VERLON_API_KEY=your-actual-api-key
VERLON_GATE_ID=your-actual-gate-id
```

3. Install dependencies:
```bash
pnpm install
```

4. Run the example:
```bash
pnpm start
```

## Expected Output

Should print the AI's response explaining quantum computing in simple terms.
